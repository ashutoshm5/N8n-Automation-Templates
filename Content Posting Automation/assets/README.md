# Workflow Asset Gallery & Screenshots

This directory contains visual documentation and architecture diagrams for the **Content Posting Automation** project.

---

## Intended Visual Assets

| Filename | Purpose | Description |
| :--- | :--- | :--- |
| `workflow-overview.png` | Main README Banner | Full-canvas screenshot of the 22-node n8n workflow canvas. |
| `workflow-architecture.png` | Architecture Schematic | Visual flow diagram showing parallel Cloudinary, Gemini, and publishing branches. |
| `setup-screenshots/` | Setup Guide Visuals | Step-by-step screenshots illustrating credential setup and node parameter configuration in n8n. |

---

### Screenshot Placeholder Notice for Repository Maintainers

When preparing this repository for public presentation or client handoff:
1. Open n8n at `http://localhost:5678`.
2. Open the **Content Posting Automation** workflow.
3. Fit the full workflow to screen (`Shift + 1` in n8n canvas) and capture a high-resolution screenshot.
4. Save the screenshot as `assets/workflow-overview.png`.
5. Capture credential setup views (with sensitive keys masked) and save them into `assets/setup-screenshots/`.
